### 9. Pedido acima do saldo → recusado (409)
>>> POST http://127.0.0.1:5002/api/pedidos
{"cliente": "Carlos Lima", "itens": [{"sku": "MON-001", "quantidade": 5}]}
<<< 409 CONFLICT
{
  "erro": "Estoque insuficiente para 'MON-001': disponível 2, solicitado 5.",
  "codigo": "ESTOQUE_INSUFICIENTE"
}
